# KRALİ - ALTYAZI

Premiere Pro için KRALİ Altyazı eklentisinin güncelleme kanalı.

Bu repository, KRALİ panelinin otomatik güncelleme manifestini ve sürüm paketlerini dağıtmak için kullanılır.

## Update channel

Panel `update/latest.json` dosyasını kontrol eder. Yeni stabil sürüm varsa paket indirilir, SHA-256 doğrulanır, mevcut sürüm yedeklenir ve güncelleme uygulanır.

> Aktif geliştirme: AUTO UPDATE altyapısı hazırlanıyor.
